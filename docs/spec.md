# Spec — haboku

<!-- このファイルは「現状の仕様」だけを表す source of truth。判断の経緯・却下案は docs/decisions/ へ。実装が仕様とずれたら、実装ではなくまずこのファイルを直すか、ずれを ADR にする -->

## 目的

ローカルの Markdown ファイルをそのまま扱うメモアプリ。1200 件規模の vault を即座に開き、検索して書ける。

保存形式は**素の `.md` ファイル**。独自 DB もロックインも持たない。他のツール（エディタ・grep・git）で
同じファイルを触れることが前提。

## 非目標（作らないもの）

<!-- スコープ外を先に言語化する。BSSN: 今の要求に無いものはここに置く -->

- **読み込み専用モード**。前身にあったが、「編集できるのに保存されない＝書いた本文が消える」経路を
  作っていたため廃止した（ADR-0002）。開いた vault は常に書ける
- **全文検索**（SQLite FTS5 / tantivy）。約 1200 件を 30ms で読めているので、当面は素の走査で足りる
- **同期・共有・マルチデバイス**。ローカル 1 台前提。外部変更との衝突解決もしない
- **タグの付け外し専用 UI**。frontmatter にあるタグで絞り込めれば足りる。分類はフォルダが主
- **WYSIWYG / プレビュー分割**。書くのは Markdown のテキストそのもの

## 機能の関数化

<!-- 仕事を関数として言語化する: 入力と出力を決め、守る制約はコード（型・テスト・バリデーション）で、良し悪しは評価基準で表す -->

| 機能 | 入力 | 出力 | 制約（コードで守る） | 評価基準（どう確かめる） |
|------|------|------|--------------------|------------------------|
| vault 読み込み | vault のルートパス | `Vec<Note>`（title / tags / folder / preview / raw） | 読めないファイルは黙って捨てず件数に出す | 約 1200 件を 50ms 以内（暖機後） |
| ノート一覧 | `Vec<Note>` + 絞り込み条件 | 一覧表示 | 集計は起動時に1回。`view()` に置かない | 打鍵時の `view()` 構築が 1ms 未満 |
| ファジー検索 | クエリ文字列, ノート群 | スコア順の上位 50 件 + マッチ範囲 | マッチ範囲は**バイト範囲**（日本語で境界を割らない） | `Cmd+P` → 数文字で目的のノートが上位に出る |
| 編集 | キー入力 | エディタ内容の更新 | 編集操作のみ dirty にする（カーソル移動では立てない） | 日本語・コードブロックが1文字も欠けない |
| 自動保存 | dirty 状態 + 経過時間 | ファイルへの書き込み | 内容が変わっていなければ**書かない**。元ファイルの**権限を引き継ぐ**（新規作成・`.rescue` も `0600`）。書き込みは**ワーカーで走らせ、`update()` を待たせない**。失敗が続く間は**指数バックオフ**（500ms→30s） | 手を止めて1秒／打ち続けても2.5秒以内。無編集の切替で mtime が動かない。`0600` のノートが保存で緩まない。**新規ノートも `0600` で生まれる**。保存できない間も UI が固まらない（`update()` の中でディスクへ書かない）。保存中の打鍵が消えない |
| ノート切替 | 選択されたノート | エディタ内容の差し替え | **保存に失敗したら切り替えない**（保存の完了メッセージで判定し、待たせていた操作を捨てる） | 保存失敗時に編集内容がエディタに残る。保存中の切替は完了後に走る |
| リネーム | 新しいファイル名 | ファイル名の変更のみ | 一覧から消える名前を作らせない（空・`/`・`\`・dot 始まりは拒否、拡張子は補う）。衝突は枝番 | 既存ファイルが潰れない。本文が書き換わらない |
| 削除 | 開いているノート | `.trash/` への退避 | 確認なし。**捨てる前に書き戻す**（失敗したら削除しない）。同名衝突は枝番 | 一覧とフォルダ件数から消え、`.trash` に**消す直前の本文**が残る |
| 終了 | ウィンドウを閉じる要求 | 保存してから終了 | **保存に失敗したら 1 回目は閉じない。2 回目は `.rescue` へ退避してから閉じる。退避にも失敗したら閉じない** | デバウンス途中で閉じても編集が消えない。保存できない状態でも強制終了せずに出られる。本文の行き先が無いまま終了しない |

## 未知の洗い出し（着手前に一度やる）

<!-- 高くつく前に安く未知を知る。blind spot pass の結果と、まだ決められないことをここに残す -->

- **Blind spot pass の結果**（この領域で見落としがちな点）:
  - **等幅フォントと CJK**。`Font::MONOSPACE` を指定すると cosmic-text が漢字に `GB18030 Bitmap` を選び、
    Swash がラスタライズに失敗して**漢字だけ画面から消える**。コードブロックを等幅で出したいので
    避けて通れない。漢字が出る等幅フォントを名指しし、必ず漢字入りの実データで確認する。
    **解決済み: `Osaka-Mono` を名指しする（ADR-0003）**
  - **キー処理**。`keyboard::listen()` は `Status::Ignored` のイベントしか流さないため、`text_input` に
    フォーカスがあるとショートカットが届かない。`event::listen_with()` を使う。ただし subscription は
    イベントを**観測できても消費できない**ので、`Cmd+P` のトグル（再押下で閉じる）は成立しない
  - **`Content::text()` の正規化**。元ファイルと 1 バイトでも違うと「無編集でも毎回書く」状態になり、
    mtime が動き続けて外部ツールから更新と誤認される。保存回数のカウンタで監視する。
    **解決済み: iced 0.14 では往復がバイト一致することを確認し、テストで固定した**
- **見て初めて決められること**（プロトタイプ・モックで先に確かめる）:
  - RSS が全件描画で 164MB になる。許容するか、可視範囲を絞るか
- **判断待ち**（決めるには情報が足りないこと）:
  - `Cmd+Shift+P`（コマンドパレット）・`Cmd+R`（リネーム）を前身と同じ形で移すか、閉じ方の制約を踏まえて
    設計し直すか。**`Cmd+P`（ノート検索）については解決済み: トグルにせず、閉じ方を
    Escape / ✕ / 背景クリックに寄せる（ADR-0004）。同じ制約が他のショートカットにも効く**。
    **`Cmd+R`（リネーム）も解決済み: ファイル名だけを変える（ADR-0006）。
    `Cmd+Shift+P`（コマンドパレット）は作っていない — 個別のショートカットで足りている**

## マイルストーン

<!-- 変わりやすい部分（データモデル・型・UX フロー）を先頭に、機械的な作業を末尾に -->

1. `vault.rs` / `fuzzy.rs` を前身から移植し、`cargo test` を通す（無改造で動くことは実証済み）
2. 3 ペイン（フォルダ / 一覧 / エディタ）+ ノート選択。等幅フォントをここで決めて実データで検証する
3. 自動保存（デバウンス 1s / 上限 2.5s / 差分なしは書かない / 失敗時は切替中断）
4. コマンドパレット（`Cmd+P`・ファジー検索・マッチ色分け・`ctrl-n`/`ctrl-p` 移動）
5. ノート新規作成（`Cmd+N`、時刻ファイル名、同一秒の衝突を避ける）
6. リネーム・削除（`.trash` へ退避。dot 始まりを拒否する）
