# ADR-0001: 初期スタックの選定

- 日付: 2026-08-09
- ステータス: 採用

## 文脈

<!-- どんな問題・制約の中で決めたか。評価軸の優先度を先に書く（総合点方式の罠を避ける） -->

haboku は gpui + gpui-component で一度完成している（公開直前まで到達）。
それを作り直すにあたって UI 基盤を選び直した。

評価軸を優先度順に置いた。**この題材は「テキストエディタ × シンタックスハイライト × 日本語入力」という、
どの Rust GUI でも最も未成熟な領域を踏む**ので、上位2つが実質的に選択を決める。

1. **日本語が書けること**（IME・preedit・候補ウィンドウ位置・CJK の表示）。書けなければ用をなさない
2. **rope ベースの複数行エディタとシンタックスハイライトが手に入ること**。自作は現実的でない
3. **メンテナンスの継続性**。壊れたときに直る見込みがあるか
4. 1200 件規模の一覧を捌ける性能
5. ビルド時間・バイナリサイズ

## 決定

<!-- 何を選んだか1〜3行 -->

**Rust + iced 0.14**（features: `highlighter`, `advanced`, `tokio`）を採用する。
シンタックスハイライトは syntect（`iced_highlighter` 経由）。

判断は評判ではなく実測で行った。検証は移植検証のリポジトリに残っている。

## 却下した代替案

<!-- 何を・なぜ見送ったか。「なぜこれでないのか」が将来いちばん効く記録 -->

### gpui / gpui-component（前身の構成）— 継続しない

動いているものを捨てる判断なので理由を厚く残す。

- **crates.io 版が 0.2.2（2025-10-22）で 9.5 ヶ月更新が止まっている。** Zed 本体は開発を続けているが
  publish されない
- **「macOS Sequoia 15.x 以降で crates.io 版が MTLCompilerService エラーで起動しない」Issue #46486 が
  `Closed as not planned` で閉じられた。** 外部アプリが起動すらしない報告への回答がこれ、というのが決定的
- Zed は 2026年2月に GPUI のコミュニティ向け開発へ "major brakes" を明言。blade → wgpu へ移行中で
  crates.io 版との乖離は広がる方向。コミュニティ fork の gpui-ce は PR 1 件で停滞
- **フェンス内コードの言語別ハイライトが実現できない。** gpui-component 0.5.1 の欠陥が3つ重なっており
  （injection 対象言語の固定 / info string 由来の言語名を読まない / テキスト述語を壊す TextProvider）、
  うち2つはアプリ側から回避不能。upstream にパッチを当てる以外に道がなかった

### 他の Rust GUI — 検討したが実測まで進めなかった

- **egui**: immediate mode。rope ベースのエディタが無く、本格的なテキスト編集は自作になる
- **floem**: Lapce チーム製でエディタ基盤の素地はあるが、iced ほどの活発さ・利用者数がない
- **Dioxus / Tauri 系**: WebView 越しなら CodeMirror 等が使えて確実だが、「Rust の GUI で作る」という
  この題材の前提から外れる
- **Xilem / Masonry**: 将来性はあるが production ready ではない

## 帰結

<!-- この決定で背負うトレードオフ。非標準技術なら innovation token の消費として明記 -->

- **前身の資産のうち UI 層は捨てる。** ただし `vault.rs` / `fuzzy.rs` は std のみ依存で無改造で動く。
  gpui で学んだ設計の型（毎フレーム走る場所に集計を置かない、保存失敗時は遷移を中断する）はそのまま生きる
- **iced もリリース間隔は長い**（0.13→0.14 で 15 ヶ月）。ただし master は日次で動いており、
  gpui の「唯一の安定版が macOS で動かないまま放置」とは質が違う
- **仕様を変える必要がある点が3つある**（詳細は ADR-0002 と `docs/spec.md`）:
  等幅フォントの名指しが必須 / `Cmd+P` のトグルが不可 / 読み込み専用モードの廃止
- **RSS は全件描画で 164MB**（gpui 版の仮想リストは 75MB）。一方 vault 読み込みは 30.1ms と速く、
  仮想リストは不要になった。メモリを詰めたくなったら可視範囲を絞る余地は残っている
