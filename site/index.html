Mac用Markdownメモアプリ

Markdown を
開いて、探して、書く

haboku は macOS 向けのメモアプリです。 ノートはディスクにある普通の .md のままなので、アプリを消しても一つも失われません。

はじめる ソースを読む

キーバインドの一覧

キーバインドの一覧
⌘P ノートを探す。⌃N と ⌃P で候補を移動し、return で開き、esc で閉じる
⌘N 新しいノートを作る
⌘R ファイル名を変える
⌘delete vault の中の .trash/ へ退避する。即時には削除しない
⌘⇧V 編集と Markdown プレビューを切り替える
⌘Z 取り消す。⌘⇧Z でやり直す
⌘W 保存を待ってから閉じる。⌘Q は同じ手順で終了する

保存に失敗した状態で閉じようとすると、最初の操作は中断されます。 もう一度閉じると、本文を .rescue ファイルへ退避してから終了します。 退避にも失敗した場合は閉じません。

ソースから動かす手順

配布しているのは macOS 向けのソースです。stable の Rust ツールチェイン（edition 2024）が要ります。

$ git clone https://github.com/hyuraku/haboku.git
$ cd haboku
$ cargo run --release

初回の起動でノートの置き場所を選びます。既定の候補は ~/Documents/haboku です。 すでにある Markdown のフォルダを選んだ場合は、それをそのまま vault として開きます。
