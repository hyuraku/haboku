# haboku

ローカルの Markdown ファイルをそのまま扱う、macOS 専用のメモアプリ。
1200 件規模の vault を一瞬で開き、検索して、書く。それだけをやる。

クラウドには一切つながない。ノートは普通の `.md` ファイルのまま、あなたのディスクに置かれる。
アプリを消しても何も失われない。

## 特徴

- **速い。** 実測で vault 読み込み 30.2ms（約 1200 件・release ビルド・暖機後）、
  打鍵時の画面構築は 1ms 未満。1000 件級の vault でも引っかからない
- **日本語に強いファジー検索。** `Cmd+P` で全ノートを絞り込み。全角/半角・ひらがな/カタカナ・
  半角カナの濁点まで正規化してマッチする
- **無編集なら 1 バイトも書かない。** ノートを開いて閉じるだけでは mtime が動かないので、
  git 管理や同期ツール配下の vault と共存できる
- **保存が壊れない。** fsync + アトミック rename で書き、失敗したらノート切替を中断して
  編集内容をエディタに残す。削除は `.trash/` への退避で、即時消去はしない
- **日本語とコードブロックが欠けない。** エディタの等幅フォントは macOS 同梱の
  `BIZ UDGothic`（ASCII 1 桁 = CJK 半分の桁揃えを実測で確認済み）

## 動作環境

**macOS 専用**（フォントの名指しと一部テストが macOS に依存する）。
ビルドには Rust ツールチェイン（edition 2024）が必要。

## インストール

```sh
git clone <this repo>
cd haboku
sh dist/build-app.sh          # → target/dist/haboku.app
cp -R target/dist/haboku.app /Applications/
```

`build-app.sh` が作る .app は ad-hoc 署名なので、**ビルドしたその Mac でしか開けない**。
他人に配るには Developer ID 署名と notarization が必要（未対応）。

.app にせず直接動かすなら:

```sh
cargo run --release           # debug ビルドは読み込みが一桁遅くなる
```

## 使い方

初回起動時にノートの保存先を選ぶ（デフォルトは `~/Documents/haboku`）。
既存の Markdown フォルダを選べばそのまま vault になる。
環境変数 `VAULT` を設定すると記憶した保存先より優先される。

| キー | 動作 |
|---|---|
| `Cmd+P` | ノート検索（パレット内は `ctrl-n` / `ctrl-p` で移動、`Enter` で開く、`Esc` で閉じる） |
| `Cmd+N` | 新規ノート（日時ファイル名で作成） |
| `Cmd+R` | ファイル名の変更 |
| `Cmd+⌫` | ノートを `.trash/` へ退避 |
| `Cmd+W` / `Cmd+Q` | 保存してから閉じる・終了する |

保存は自動。手を止めると 1 秒以内、打ち続けても 2.5 秒以内に書かれる。
**`Cmd+Q`・`Cmd+W`・✕ はどれも保存を待ってから終了する**ので、打った直後に終わらせても消えない。
保存できない状態で閉じようとすると 1 回目は止まり、2 回目で本文を `.rescue` に退避してから終了する。

## 前提と割り切り

- **vault は haboku 単独で触る前提。** 他のエディタで同じファイルを**同時に**開いて編集すると、
  外部の変更は検知されず上書きされる（git 併用や、閉じているときに他ツールで触るのは問題ない）
- **本文の検索はタイトルと当て方が違う。** タイトルは飛び飛びでも当たるファジー検索だが、
  本文は**打った語がそのまま含まれるもの**だけが当たる（長文はどんなクエリにも飛び飛びで
  当たってしまうため）。索引は持たず毎回走査するので、当たったノートは常に最新
- **終了時の保存ガードが効くのは `Cmd+Q`・`Cmd+W`・✕ の 3 つ。** Dock アイコンの右クリック →
  終了、ログアウト、`osascript` の quit は OS がプロセスを直接終わらせるので通らない
  （消えるのは自動保存の上限 2.5 秒ぶんまで。ADR-0021）
- `BIZ UDGothic` が無い環境では別の等幅フォントに静かにフォールバックする（桁揃えは保証されない）
